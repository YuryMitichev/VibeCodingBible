# Architecture Decision Records

Каталог **ADR** (Architecture Decision Records) — архитектурные решения проекта.

## Формат

- Имя файла: `ADR-NNNN-short-title.md`
- Шаблон: [templates/adr.template.md](../../templates/adr.template.md)

## Индекс

| ADR | Название | Статус | Дата |
|---|---|---|---|
| [ADR-0001](ADR-0001-use-markdown.md) | Use Markdown and Git as Foundation | Accepted | 2026-07-11 |

## Когда создавать ADR

- выбор технологии или формата;
- изменение структуры репозитория;
- решение, влияющее на долгосрочную поддержку проекта.

Операционные изменения (новая глава, правка текста) оформляются через ECR, а не ADR.
