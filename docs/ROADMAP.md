# Roadmap

Version: 0.2.0
Status: Active
Last updated: 2026-07-11

---

## Обзор

Дорожная карта описывает этапы разработки **Vibe Coding Bible** от Bootstrap до первой публикации.

Версионирование — семантическое. Каждая фаза имеет чёткие критерии завершения.

---

## Фазы

### 0.1.0 — Bootstrap ✓

**Статус:** Завершено

- Создана структура репозитория
- Инициализированы каталоги book/, docs/, templates/, prompts/
- Базовые заглушки глав и документов

---

---

### 0.3.0 — Outline

**Статус:** Запланировано

**Цель:** Финализировать структуру книги.

**Задачи:**

- Нумерация и именование всех 80 глав
- Создание файлов-заглушек для каждой главы в book/
- Карта зависимостей между главами
- Определение объёма каждой части
- Согласование приложений (A–J)

**Критерий завершения:** Каждая глава имеет файл в book/ с описанием содержания.

---

### 0.5.0 — First Draft

**Статус:** Запланировано

**Цель:** Черновики всех глав.

**Задачи:**

- Часть I — Основы Vibe Coding (главы 1–8)
- Часть II — Работа с ИИ (главы 9–18)
- Часть III — Проектирование (главы 19–28)
- Часть IV — Разработка (главы 29–38)
- Часть V — Большие проекты (главы 39–48)
- Часть VI — AI-first разработка (главы 49–58)
- Часть VII — Практические проекты (главы 59–68)
- Часть VIII — Лучшие практики (главы 69–76)
- Часть IX — Будущее профессии (главы 77–80)
- Часть X — Приложения (A–J)

**Критерий завершения:** Каждая глава содержит все обязательные разделы (см. STYLE_GUIDE), даже если качество черновое.

---

### 0.8.0 — Technical Review

**Статус:** Запланировано

**Цель:** Редактура и техническая проверка.

**Задачи:**

- Вычитка всех глав
- Проверка терминологии и перекрёстных ссылок
- Устранение противоречий
- Проверка примеров кода и диаграмм
- Наполнение GLOSSARY и BIBLIOGRAPHY
- Реализация сборки (PDF, EPUB, DOCX)

**Критерий завершения:** Нет известных логических ошибок. Единый стиль. Примеры воспроизводимы.

---

### 1.0.0 — First Public Release

**Статус:** Запланировано

**Цель:** Публикация книги.

**Задачи:**

- Финальная редактура
- Сборка в PDF, EPUB, DOCX
- Публикация (формат определяется позже)
- Release checklist

**Критерий завершения:** Книга доступна читателям в выбранных форматах.
