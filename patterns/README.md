# Patterns

Паттерны и повторяемые решения.

## Назначение

Каталог зарезервирован для описания паттернов:

- организации knowledge monorepo;
- написания глав и документации;
- взаимодействия с ИИ-инструментами;
- структурирования контента книги.

Содержание добавляется по мере накопления практики.
