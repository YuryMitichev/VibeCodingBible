# Workflows

Рабочие процессы Vibe Publishing Framework.

## Назначение

Каталог описывает повторяемые сценарии работы:

- жизненный цикл ECR (создание → выполнение → отчёт);
- написание и ревью глав;
- релиз и сборка артефактов;
- синхронизация документации и терминологии.

Каждый workflow — отдельный markdown-файл с шагами, ролями и критериями готовности.
