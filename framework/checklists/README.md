# Checklists

Чек-листы Vibe Publishing Framework.

## Назначение

Каталог содержит чек-листы для типовых операций фреймворка:

- завершение ECR;
- подготовка релиза;
- ревью главы или документа.

Готовые чек-листы проекта «Vibe Coding Bible» могут находиться в [checklists/](../../checklists/) в корне репозитория.
