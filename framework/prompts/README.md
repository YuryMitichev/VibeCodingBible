# Prompts

Промпты Vibe Publishing Framework.

## Назначение

Каталог содержит шаблоны и готовые промпты для ИИ-инструментов:

- bootstrap-промпты для инициализации сессии;
- промпты для написания и ревью глав;
- промпты для выполнения ECR и служебных задач.

Промпты, специфичные для текущей книги, могут дублироваться или ссылаться из [prompts/](../../prompts/) в корне репозитория.
