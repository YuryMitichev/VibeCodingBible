# Vibe Publishing Framework

Универсальный фреймворк для долгосрочной разработки книг, курсов и knowledge monorepo.

## Назначение

Каталог `framework/` содержит переиспользуемые артефакты, не привязанные к конкретному содержанию «Vibe Coding Bible»:

- **prompts/** — промпты для ИИ-инструментов
- **templates/** — шаблоны документов (ECR, главы, отчёты)
- **rules/** — правила и конвенции для агентов и участников
- **workflows/** — описания рабочих процессов
- **schemas/** — схемы и форматы данных
- **checklists/** — чек-листы для типовых операций
