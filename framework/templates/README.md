# Templates

Шаблоны документов Vibe Publishing Framework.

## Назначение

Каталог содержит минимальные заготовки для типовых артефактов:

- **ECR_TEMPLATE.md** — шаблон Engineering Change Request
- другие шаблоны процессов и отчётов фреймворка

Шаблоны содержания книги (главы, PRD, ADR, RFC) находятся в [templates/](../../templates/) в корне репозитория.
