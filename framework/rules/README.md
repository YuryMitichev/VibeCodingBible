# Rules

Правила и конвенции Vibe Publishing Framework.

## Назначение

Каталог содержит постоянные инструкции для участников проекта и ИИ-агентов:

- соглашения об именовании файлов и каталогов;
- правила оформления документов;
- ограничения и guardrails для автоматизации.

Правила здесь — **универсальные** и применимы к любому проекту на базе фреймворка. Специфика «Vibe Coding Bible» описана в [docs/](../../docs/).
