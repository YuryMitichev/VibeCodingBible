# Logs

Система логирования Vibe Publishing Framework.

## Назначение

Каталог хранит отчёты о выполненных изменениях и завершённых задачах.

## Отчёты по ECR

После завершения каждой задачи **ECR-XXXX** создаётся отчёт в:

```
logs/completed/
```

## Рекомендуемый формат отчёта

Имя файла: `ECR-XXXX-report.md`

Содержание:

- идентификатор и название ECR;
- дата завершения;
- краткое резюме изменений;
- список затронутых файлов;
- результат проверки (критерии готовности);
- заметки и follow-up (если есть).

## Связь с задачами

| Артефакт | Расположение |
|---|---|
| Задача (в работе / завершена) | [tasks/](../tasks/) |
| Отчёт о выполнении | `logs/completed/` |
