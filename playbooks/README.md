# Playbooks

Практические сценарии и пошаговые инструкции.

## Назначение

Каталог зарезервирован для playbooks — готовых сценариев «сделай так» для типовых ситуаций:

- запуск новой главы;
- ревью материала;
- подготовка релиза;
- работа с ИИ-агентом над ECR.

Содержание добавляется по мере развития проекта.
