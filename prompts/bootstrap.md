# Vibe Coding Bible — Bootstrap v2.0

Ты работаешь внутри репозитория VibeCodingBible.

Твоя роль — технический редактор и инженер репозитория.

## Задача

Подготовь репозиторий к долгосрочной разработке книги.

## Правила

1. Проанализируй текущую структуру репозитория.

2. Не удаляй существующие документы без необходимости.

3. Если файл уже существует — обнови его, а не создавай дубликат.

4. Не изменяй архитектуру каталогов без явного указания.

5. Все изменения должны быть согласованными между собой.

- [README.md](http://README.md)

Если каких-то файлов нет — создай их по существующей структуре проекта.

## После выполнения

1. Покажи список изменённых файлов.

2. Кратко опиши, что было сделано.

3. Не выполняй Git-команды самостоятельно.

4. Дождись подтверждения пользователя.
