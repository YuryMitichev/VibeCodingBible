# 1. Mission

Создать лучшую практическую книгу по Vibe Coding.

Книга должна научить читателя самостоятельно создавать проекты любой сложности вместе с AI — от идеи до релиза.

Главная цель первой версии книги:

Выпустить книгу.

Получить первых платящих читателей.

Только после этого развивать Framework и инфраструктуру.

---

# 2. Core Principles

Главное правило:

Контент важнее инфраструктуры.

Соотношение:

90% написание книги

10% поддержка проекта

Мы не создаём документацию ради документации.

Мы создаём книгу.

---

# 3. Positioning

Эта книга НЕ является:

• книгой про ChatGPT

• книгой про Cursor

• книгой про промпты

• учебником по Python

• каталогом AI-сервисов

Это книга о новой инженерной профессии.

Главная мысль:

AI не заменяет инженера.

AI усиливает инженера, который умеет думать.

---

# 4. Target Reader

Читатель хочет:

• создавать реальные продукты;

• использовать AI профессионально;

• научиться мыслить как AI-first инженер;

• доводить проекты до релиза.
